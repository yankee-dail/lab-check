# Lab Check

Сервіс для захисту лабораторних робіт. Студент завантажує свою роботу (код, архів, звіт), сервіс складає тест із 10 питань саме по його коду та лекції, а студент проходить тест у повноекранному режимі з обмеженим часом на кожне питання. Після завершення викладач отримує на пошту звіт з оцінкою, відповідями, журналом дій і файлами роботи.

## Можливості

- **Студент** (`/`): обирає лабораторну, вказує ПІБ і групу, завантажує файли: код будь-якою мовою, `.zip`, `.pdf`, `.docx`, `.ipynb`.
- **Тест** (`/test`): 10 питань з 4 варіантами, по 40 секунд на питання (налаштовується), без повернення назад. Час рахує сервер, тому перезавантаження сторінки таймер не скидає.
- **Контроль**:
  - тест іде лише в повноекранному режимі; вихід із нього — порушення, і питання закривається екраном-заглушкою;
  - перехід на іншу вкладку, згортання вікна чи втрата фокусу — порушення; після 3 порушень (налаштовується) тест закривається;
  - копіювання, виділення, права кнопка, Ctrl+C/A/S/P/U, друк і клавіші інструментів розробника заблоковані, а кожна спроба записується в журнал;
  - текст питань малюється на canvas з водяним знаком (ПІБ студента), тож скопіювати його не вийде;
  - для кожної відповіді записується час; однаково довгі паузи і відповіді в останні секунди позначаються як підозрілі.
- **Викладач** (`/admin`): створює лабораторні, завантажує лекцію (PDF, DOCX, PPTX, TXT або текстом), бачить результати, питання, журнал дій, може завантажити файли студента, переслати звіт, видалити спробу (дозволити перездачу) і вивантажити CSV.
- **Звіт на пошту** приходить після завершення тесту, після примусового закриття за порушення, а також якщо студент покинув тест (10 хв без активності).

## Змінні середовища

| Змінна | Опис |
|---|---|
| `DATABASE_URL` | Postgres |
| `ANTHROPIC_API_KEY` | ключ API для генерації питань |
| `ADMIN_PASSWORD` | пароль до `/admin` |
| `TEACHER_EMAIL` | куди надсилати звіти (можна кілька через кому) |
| `RESEND_API_KEY` | ключ [Resend](https://resend.com) для відправки листів |
| `MAIL_FROM` | відправник, за замовчуванням `Lab Check <onboarding@resend.dev>` |

Без верифікованого домену Resend надсилає листи лише на адресу, з якою зареєстровано акаунт, тож зареєструйтеся на ту ж пошту, що й `TEACHER_EMAIL`.

## Локальний запуск

```bash
cp .env.example .env   # заповнити значення
npm install
npm run dev
```

## Деплой на Railway

Проєкт: web-сервіс + Postgres. `DATABASE_URL` задається посиланням `${{Postgres.DATABASE_URL}}`, а секрети зберігаються лише в Railway Variables. Схема бази створюється автоматично під час старту.

```bash
railway up --service lab-check-web
```

## Обмеження

Сайт не бачить телефон поруч зі студентом. Основний захист у тому, що часу на питання мало, а відповісти на питання про конкретний код може лише той, хто сам у ньому розібрався.
